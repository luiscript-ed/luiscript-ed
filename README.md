### Projetos em Andamento

#### 📁 YOFI

Aplicação de gerenciamento financeiro desenvolvida para facilitar o controle de ganhos, gastos, contas e cartões. O projeto também conta com uma assistente de IA financeira chamada **MYA**, responsável por análises e dicas relacionadas às finanças do usuário, ela atualmente usa o gemma 4-31B. O projeto está disponível para qualquer um em: [YOFI](https://luiscript-ed.github.io/YOFI/). O projeto está em testes, pode ser que esteja com lentidão ou mal funcionamento. A ideia é futuramente transformar em APK e disponibilizar na play store. (Obs: Vale ressaltar que é um projeto em equipe, eu sou responsável principalmente pelas rotas e banco de dados) 

**Tecnologias:**
- HTML5
- CSS3
- JavaScript
- FastAPI
- PostgreSQL

#### 📁 Luminaris

Projeto de RPG desenvolvido no Roblox, com foco em exploração, combate, progressão e construção de um mundo próprio. O projeto utiliza diferentes sistemas de combate, habilidades, armas, mana e organizações dentro do universo do jogo. O jogo é bem complexo, então foi meio que um desafio começa-lo, atualmente ele conta com sistema de dados no DataStore, Diversas Skills e Espadas (VFX nativa + Modelo Própio ou Nativo), todos contém sistema de dano e cooldown. Contém 2 place´s de experiência, cheios de lugares variados, easter egg e uma arquitetura pensada na experiência do usuário.

**Tecnologias:**
- Roblox Studio
- Luau
- Blender
